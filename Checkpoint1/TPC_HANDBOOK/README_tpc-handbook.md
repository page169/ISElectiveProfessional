# TPC Handbook Assistant

IS Professional Elective #4 (Generative AI Systems) — Semester Capstone
**Checkpoint 1: Foundation & Data Pipeline** (Prelim, Performance Task 1)

## What this project is

TPC Handbook Assistant is a Retrieval-Augmented Generation Q&A chatbot
grounded in the Talibon Polytechnic College Student Handbook. It answers
questions about admission, grading, student services, conduct and
discipline, and administrative policies in plain language, always pointing
back to the specific Article/Chapter/Section of the handbook an answer
came from — instead of a generic or guessed policy answer.

This theme was assigned by the instructor, replacing the team's earlier
proposed topic.

## Dataset

The raw dataset was built by extracting the instructor-provided TPC Student
Handbook v.04 PDF (202 pages) with `pdftotext -layout`, then splitting the
text into 41 documents along the handbook's own Article/Chapter/Section
structure (e.g., "Article II, Chapter 6: Grading System"), plus standalone
reference sections (Data Privacy Consent Form, Student-Related Law and
Memoranda, Courses and Programs Offered) and the five-article Off-Campus/OJT
policy annex. The dense course-curriculum "Prospectus" tables were
intentionally excluded from this checkpoint — see `docs/reflection.md` for
why, and the plan to revisit with table-aware extraction later.

## How to run

```bash
# 1. Preprocess the raw dataset
python3 src/preprocessing.py

# 2. Generate sample embeddings
pip install sentence-transformers scikit-learn
python3 src/embedding_demo.py
```

`embedding_demo.py` is written against `sentence-transformers/all-MiniLM-L6-v2`
(the intended production model). If run without internet access to
huggingface.co, it automatically falls back to a local TF-IDF vectorizer
purely so the pipeline is still runnable end-to-end offline — see the
docstring in that file and `docs/embedding_report.md` for details.
